# Dzień 3 — terminal, foldery i pliki

## Najważniejsze komendy

| Komenda | Znaczenie |
|---|---|
| `pwd` | pokazuje aktualny folder |
| `ls` | pokazuje zawartość folderu |
| `cd folder` | przechodzi do folderu |
| `cd ..` | wraca folder wyżej |
| `mkdir nazwa` | tworzy folder |
| `New-Item plik.txt` | tworzy plik |
| `cat plik.txt` | pokazuje zawartość pliku |
| `copy a.txt b.txt` | kopiuje plik |
| `ren stara.txt nowa.txt` | zmienia nazwę pliku |
| `rm plik.txt` | usuwa plik |
