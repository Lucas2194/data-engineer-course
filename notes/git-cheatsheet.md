# Git Cheatsheet

## Podstawowe komendy

| Komenda | Znaczenie |
|---|---|
| `git status` | pokazuje stan repozytorium |
| `git add plik` | dodaje plik do staging area |
| `git commit -m "message"` | zapisuje commit |
| `git diff` | pokazuje niezacommitowane zmiany |
| `git diff --staged` | pokazuje zmiany w staging area |
| `git log --oneline` | pokazuje krótką historię |
| `git restore plik` | cofa niezacommitowane zmiany w pliku |
| `git restore --staged plik` | usuwa plik ze staging area |
