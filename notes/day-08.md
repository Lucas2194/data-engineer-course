# Dzień 8 — Python: warunki if, elif, else

## 1. Główna idea dnia

Warunki pozwalają programowi podejmować decyzje.

Program nie musi już wykonywać zawsze tych samych instrukcji. Może sprawdzić, czy coś jest prawdą, i na tej podstawie wykonać różny kod.

Przykład z życia:

- jeśli pada deszcz, biorę parasol,
- jeśli nie pada, wychodzę bez parasola.

Przykład w Pythonie:

```python
if warunek:
    wykonaj_kod
else:
    wykonaj_inny_kod
