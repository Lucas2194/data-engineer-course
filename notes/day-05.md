# Dzień 5 — GitHub

## Co dzisiaj zrobiłem?

- założyłem albo przygotowałem konto GitHub
- utworzyłem repozytorium data-engineer-course
- połączyłem lokalne repozytorium ze zdalnym repozytorium
- użyłem git remote add origin
- użyłem git push -u origin main
- wysłałem projekt online

## Najważniejsze komendy

| Komenda | Znaczenie |
|---|---|
| `git branch` | pokazuje branche |
| `git branch -M main` | zmienia nazwę aktualnego brancha na main |
| `git remote add origin ADRES` | dodaje zdalne repozytorium |
| `git remote -v` | pokazuje zdalne repozytoria |
| `git push -u origin main` | pierwszy push na GitHub |
| `git push` | kolejne wysyłanie zmian |

## Różnica między commit a push

Commit zapisuje zmianę lokalnie.

Push wysyła commity na GitHub.
