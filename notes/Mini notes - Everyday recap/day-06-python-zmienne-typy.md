# Dzień 6 - Python: zmienne i typy danych

## Najważniejsze

- Zmienna przechowuje wartość pod wybraną nazwą.
- Python ma różne typy danych, między innymi `str`, `int`, `float` i `bool`.
- Typ danych wpływa na to, jakie operacje można wykonać.
- Nazwy zmiennych powinny opisywać zawartość.

## Mini przykład

```python
customer_name = "Anna"
order_id = 1001
total_amount = 249.99
is_paid = True
```

## Zapamiętaj

- `str` to tekst.
- `int` to liczba całkowita.
- `float` to liczba dziesiętna.
- `bool` to `True` albo `False`.
- `type(value)` pokazuje typ wartości.
