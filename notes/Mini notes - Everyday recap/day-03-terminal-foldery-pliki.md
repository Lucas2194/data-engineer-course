# Dzień 3 - terminal, foldery i pliki

## Najważniejsze

- Terminal pozwala tworzyć foldery, pliki i przechodzić między katalogami.
- Ścieżka mówi, gdzie znajduje się plik lub folder.
- Komendy terminala są podstawą pracy w projektach data engineeringowych.

## Mini przykład

```bash
mkdir notes
touch notes/example.md
ls notes
```

## Zapamiętaj

- `mkdir` tworzy folder.
- `touch` tworzy pusty plik.
- `cd ..` cofa do folderu wyżej.
- `ls` pomaga szybko sprawdzić, co jest w danym miejscu.
