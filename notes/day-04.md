# Dzień 4 — Git głębiej

## Co dzisiaj ćwiczę?

- git status
- git add
- git commit
- git diff
- git log
- git restore
- dobre opisy commitów

## Moja notatka

Git pozwala zapisywać historię zmian w projekcie.

## Dodatkowa notatka

Commit powinien opisywać jedną konkretną zmianę.

## Staging

Staging area to miejsce przygotowania zmian do commita.
Staging area pozwala wybrać, które zmiany trafią do commita.
